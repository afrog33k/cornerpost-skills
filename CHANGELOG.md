## 0.1.0 — 29 October 2026

First versioned repository release.

- Package the existing guided onboarding workflow and Twenty operator guide with generic examples.

This is the initial rollback baseline; no earlier versioned repository release exists. Earlier Gist revisions remain unversioned and unchanged. Future releases must retain previous release commits/assets and use new version numbers for changed content.
