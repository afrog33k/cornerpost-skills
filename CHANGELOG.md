# Changelog

## 0.1.0 — 29 October 2026

First versioned repository release.

- Package the existing guided onboarding workflow and Twenty operator guide with generic examples.
- Add a companion skill and guide for source verification, owner-enrolled native update checks, staged downloads, supported activation and rollback.
- Add stable package IDs, a version manifest, exact file checksums, source provenance and a blank private installed-receipt template.
- Preserve local customization and separate check/stage/activation states. No executable installer, daemon, connection or recipient schedule is included.

This is the initial rollback baseline; no earlier versioned repository release exists. Earlier Gist revisions remain unversioned and unchanged. Future releases must retain previous release commits/assets and use new version numbers for changed content.
